## Project Description
This is an OOP Python project that uses a Tkinter GUI to suggest recipes based on ingredients entered by the user. It also shows missing ingredients and suggests substitutes.

## File Structure
- `data_models.py`: OOP classes for recipe data models.
- `recipe_data.py`: recipe database and substitute system.
- `recipe_generator.py`: ingredient matching and recommendation logic.
- `ai_recipe_generator_gui.py`: Tkinter GUI and app startup.

## How To Run
Run this command from inside this folder:

```bash
python3 ai_recipe_generator_gui.py
```

If using Homebrew Python on macOS:

```bash
/opt/homebrew/bin/python3.13 ai_recipe_generator_gui.py
```
